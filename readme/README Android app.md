


### **Android aplikacija (UI/klijent)**


## Detektivska igra

Ovaj deo projekta predstavlja korisnički interfejs aplikacije razvijen u Jetpack Compose tehnologiji. 



##  Funkcionalnosti aplikacije

- Registracija i prijava korisnika
- Pregled i učitavanje AI-generisanih priča
- Navigacija ekrana
- Offline rad pomoću Realm baze (lokalni keš)
- Sinhronizacija sa serverom pomoću Retrofit-a


##  Tehnologije

| Tehnologija      | Svrha                                  |
|------------------|-----------------------------------------|
| Kotlin           | Glavni jezik aplikacije                |
| Jetpack Compose  | UI framework                             
| Hilt             | Dependency injection                   |
| Retrofit         | HTTP komunikacija                      |
| Realm            | Lokalna baza podataka (keš)   |
| Navigation       | Navigacija ekrana|
