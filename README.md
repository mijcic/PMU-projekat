# WHODUNIT - AI Detective Android App

## Project Description
This Android application combines **detective gameplay** with **AI technologies**. Users solve AI-generated cases through interactive storytelling and clue collection. The app includes a fully interactive mobile client, a web-based admin panel, and server-side AI integration.

Key features include:
- AI-generated detective cases powered by **Gemini Pro AI**.
- Interactive storytelling with clue collection.
- Admin web interface for managing stories and AI requests.
- Local caching with **Realm** to improve app performance.
- Communication between app and server via **Retrofit** and **Ktor**.
- Backend testing and database management with **MySQL**.

## Tech Stack
- **Frontend (Android):** Kotlin, Jetpack Compose  
- **Backend (Server & Web):** Ktor, MySQL  
- **Local Storage:** Realm  
- **Networking:** Retrofit  
- **AI Integration:** Gemini Pro AI  

## Project Highlights
- Full-stack Android app with offline-first support.
- Admin workflow handles AI-generated content validation before publishing.
- Tested backend APIs and data flow.
